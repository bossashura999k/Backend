Backend Learning Starts!!!
1. npm init -y  <!-- Creates a package.json file. -->
2. Sign up on MongoDB and Create a Cluster.
3. Make a .env <!-- Used to store sensitive data. -->
4. Store your MongoDB cluster username and password in .env
5. Create a constants.js file <!-- Used to store important values so that they can be accessed from different parts of your database -->
6. Create an app.js <!-- Where you import your express app -->
7. Create a .gitignore <!-- Used to ignore node_modules/, .env and other files you don't want pushed -->
8. Create a database.js <!-- For Connecting to MongoDB and Database -->
9. Create a script.js or index.js <!-- Used to start the server. -->
